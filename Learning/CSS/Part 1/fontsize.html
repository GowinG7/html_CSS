# Font size is the CSS property that controls the size of the text.

There are two types of font-size units in CSS:
1. Absolute units: This does not change the text size whatever the size of the screen. Units are: px, pt, cm, mm, in, pc
px is most commonly used unit. 1 in = 96 px
2. Relative units: These units change the text size based on the screen size environment. These units are useful for responsive design. Units: em, rem, %, vw, vh
